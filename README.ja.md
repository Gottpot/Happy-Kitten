# 🐾 Happy-Kitten v1.2

[English](README.md) · **日本語** · [Deutsch](README.de.md)

**作者: Gottpot** · MITまたはApache-2.0のオープンソース · 📺 [YouTube @Gottpot](https://www.youtube.com/@Gottpot)

**ハッピーキトゥン**は、Mac用のローカルで動く超高速な動画編集ソフトです。Rustで作られ、映像の処理は **wgpu/Metal** でGPUが行います。画面はAdobeのグレーではなく、あまーいパステルピンク。
すべて**オフライン**で動きます。クラウドも、アカウントも、テレメトリ（利用状況の送信）も、サブスクもありません。

## ダウンロードと初回起動

[Releases](../../releases) から `Happy-Kitten-….zip` をダウンロードし（Apple Silicon の Mac、macOS 13以降）、解凍して「アプリケーション」フォルダへ移動します。

作者は **Apple の認定デベロッパーではない**ため、このアプリは公証（notarization）されていません。macOS が「壊れているため開けません」や「開発元を確認できません」と表示して起動を止めることがあります。その場合は次のどちらかを行ってください。

1. アプリを右クリック（またはControlを押しながらクリック）→「開く」。macOS 15以降は、一度開こうとしてから「システム設定 → プライバシーとセキュリティ」の「このまま開く」を押します。
2. ターミナルで、ダウンロード時に付く隔離フラグを外します。

```bash
xattr -dr com.apple.quarantine /Applications/Happy-Kitten.app
```

ソースコードから自分でビルドすれば（下記）、この警告は出ません。ソースコードは公開されており、ネットワーク通信のコードは含まれていません。

## ソースコードから起動する

```bash
# 最初に一度: Rust をインストール (https://rustup.rs)、その後
cargo run --release -p happy-kitten
# またはアプリ本体と GitHub Releases 用の ZIP を作る:
./scripts/bundle.sh      # dist/Happy-Kitten.app ができます
```

新しいプロジェクトは空なので、すぐに自分のファイルで始められます。ウィンドウにドラッグするか「インポート」を使ってください。

## 言語

右上の言語ボタン（地球儀と国コード）で、画面の言語を **DE · EN · JP · KR · ES** から切り替えられます。初回起動時は macOS の言語を使い（対応外なら英語）、選んだ言語はアプリのフォルダの `settings.json` に記憶されます。開発時は `HK_LANG=ja` で言語を固定できます。

翻訳はドイツ語の原文をキーにしています: `tr("Speichern")`、プレースホルダー付きは `trf!("{n} Clips ausgewählt", n = 3)`。すべての翻訳は `apps/happy-kitten/src/i18n_data.rs`（列: English、日本語、한국어、Español）にあり、空の項目がないことやプレースホルダーが一致していることをテストで確認します。新しい文言は、コードのキーを `tr(…)` で囲み、表に1行足すだけです。言語を増やすには `Lang` に項目を、表に列を足します。翻訳がない場合はドイツ語が表示されます。

翻訳は機械的な支援で作られたもので、ネイティブの方による校正はまだありません。修正はプルリクエストで大歓迎です。

## 使い方

| やりたいこと | 方法 |
|---|---|
| メディアをインポート | 「インポート」(⌘I) またはプールの「ファイル」で**複数のファイルを一度に**選べます。「フォルダー」はフォルダー内のすべての動画・画像・音声・字幕を取り込みます。ウィンドウにドラッグしてもOKです |
| 2種類のインポート | プールの上部で **このプロジェクト**（ファイルはこのプロジェクト専用）か **グローバル**（すべてのプロジェクトで使えるライブラリ。`~/Library/Application Support/Happy-Kitten/library.json` に保存され、ファイルは元の場所に残ります）を選びます。グローバルのクリップも通常どおりタイムラインにドラッグでき、右クリックでプロジェクトに取り込む／削除できます |
| テキストを追加 | **テキスト**タブ: プリセットをトラックにドラッグするか＋をクリック。テキストクリップを選ぶと、左側でテキスト・フォント・サイズ・色・縁取り・背景・影・配置・位置・フェードイン／アウトを変更できます |
| 字幕と歌詞 | **テキスト**タブ →「SRT · LRC · TXT」（またはファイルをウィンドウにドロップ）: 1行ごとに新しいトラックのテキストクリップになります。「トラック内のすべてのテキストにスタイルを適用」と「行をカラフルに色付け」で一括変更できます |
| 動画の上にグラフィック | **グラフィック**タブ →「グラフィック (PNG)」、または透明なPNGをビデオトラックにドラッグします（透明部分のある画像は自動でグラフィックになります。どの画像でも右クリックの「グラフィックとして動画の上に重ねる」が使えます）。クリップを選んで**サイズ・位置・回転・不透明度**とフェードイン／アウト（クロスフェード、モザイク、渦巻き、ズームなど）を設定します。複数のグラフィックの同時変更もテキストと同じです |
| 複数のテキストに同じスタイルを適用 | テキストを選び、**テキスト**タブの上部でプリセットを選んで「{n}個のテキストに適用」を押します。プリセットカードの**金色のチェック**、またはカードやタイムライン上のテキストクリップを**右クリック**（「プリセットを適用」）でも可能です。文言は変わらず、「プリセットの位置も反映」にチェックがなければ位置も変わりません |
| トラックを増やす | タイムラインの「ビデオトラック」／「オーディオトラック」（各8本まで）。上のビデオトラックが下のトラックに重なり、テキストは映像の上に表示されます。トラック名を右クリックすると空のトラックを削除できます |
| タイムラインに置く | カードをトラックにドラッグ、ダブルクリック、または＋をクリック |
| 移動 | クリップをドラッグ（端や再生ヘッドに吸着し、重なることはありません） |
| 複数のクリップを選択 | **トラックの空いた場所をドラッグ**（選択枠）、⇧/⌘クリック、または⌘A。ドラッグで全部まとめて移動、Deleteで全部削除、⇧Deleteで隙間を詰めます |
| 複数のテキストをまとめて変更 | テキストを選んで**テキスト**タブで変更: 変更は選択したすべてのテキストに反映されます（文言だけは各テキストのままです） |
| 多くの切れ目に切り替え | クリップを選んで**切り替え**タブで切り替えをクリック: 選んだクリップ同士のすべての切れ目に入ります |
| 切り替えの長さ | 切り替えタブの「長さを指定」で新しい切り替えの長さを決める、タイムライン上のピンクの帯の端をドラッグする、または切り替えをクリックしてタイムライン上のフィールドで設定します |
| 画面比率 | プレビューの上: **16:9**、**9:16**（ショート、リール、TikTok）、1:1、4:5。「全体表示」「塗りつぶし」（切り抜き）「ぼかして塗りつぶし」で、形の違う画像の扱いを選びます |
| トリミング | クリップの端をドラッグ |
| 分割 | 再生ヘッドを置いて **S**（または⌘B）: 選択したクリップを、なければ再生ヘッド上のすべてのクリップを分割します |
| 削除 | **Delete**。**⇧**を押すと隙間が詰まります（右クリックでも可） |
| 切り替えを入れる | 「切り替え」タブで2つのクリップの間にドラッグ。長さと種類はタイムライン上のフィールドで変更できます |
| 再生 | **スペース**。←/→で1フレーム移動、Home/Endで先頭／末尾へ |
| 元に戻す／やり直す | ⌘Z / ⇧⌘Z |
| サウンド設定 | オーディオまたはビデオのクリップを選び、**オーディオ**タブ →「サウンド」: **音量**（0〜200 %）、**フェードイン**、**フェードアウト**、そして**エフェクト**（エコー、リバーブ、こもった音、電話）と強さのスライダー。複数のクリップをまとめて変更できます。プレビュー、再生、書き出しで同じ音になります |
| 色の調整 | ビデオクリップか画像を選び、**色**タブ: **色温度**（寒色〜暖色）と**色合い**（グリーン〜マゼンタ）。プレビューと書き出しにそのまま反映され、複数のクリップをまとめて変更できます |
| 保存／開く | ⌘S / ⌘O（`.kitten` ファイル、中身は普通のJSON）。保存すると、緑色の通知「保存しました ✓」とファイルの場所が数秒間表示されます |
| ムービーを書き出す | 「書き出す」→ 音声付きMP4（H.264またはHEVC）。形式はプロジェクトと同じか 16:9、**9:16 ショート**、1:1、4:5。解像度は短辺（720 / 1080 / 2160ピクセル）。**フレームレート**（23.976 · 24 · 25 · 29.97 · 30 · 50 · 59.94 · 60。たとえばMidjourneyの素材なら24）。**ビットレート**は自動または手動（1〜150 Mbit/s）。**音声**は 32 / 44.1 / 48 kHz（AAC）、128〜320 kbit/s |
| 静止画 | 「静止画」で現在のプレビュー画像をPNGで保存します |
| クラッシュ対策 | 未保存の作業は30秒ごとに別の場所へコピーされ（`~/Library/Application Support/Happy-Kitten`）、クラッシュ後の次回起動時に復元されます。「新規」「開く」や終了の前には確認が出ます |

## ファイル一覧

**ファイル**タブ（とオーディオ）には、検索、フィルター（種類、使用済み／未使用）、並べ替えがあります。表示は3種類: **タイル**、**リスト**（ファイル名を省略せず表示）、**表**（名前、種類、長さ、サイズ、フォルダー。列の見出しをクリックで並べ替え）。すでにタイムラインにあるものには、どの表示でも**金色のチェック**と金色の枠が付きます。ツールチップでフルパスが見られます。

## フォント、日本語、その他の文字

フォント一覧は、それぞれのフォントの字形で表示されます。フォントに文字がない場合（日本語・中国語・韓国語）は、合う Mac のフォント（ヒラギノ、Apple SD Gothic）が自動で補います。スペースのない日本語は文字の間で折り返されます。縦向きでは、文字サイズは画像の幅に合わせます。

## エフェクト付きテキスト

テキストは Mac のフォントで描かれ（折り返し、縁取り、影、背景ボックス）、GPUでアニメーションします。フェードイン／アウトは、クロスフェード、**モザイク**、**渦巻き**、ぼかし、上へスライド、ズームイン、波、グリッチから選べます。
`cargo run -p hk-gpu --example text_sheet -- text.png` で、すべてのエフェクトを5段階で確認できます。
自分のスタイルは**グローバルプリセット**として保存し、どのプロジェクトでも使えます。

## 肉球トランジション

すべての切り替えは WGSL シェーダー（`crates/hk-gpu/src/transitions.wgsl`）で、肉球や爪を**距離場から数式で**描いています。あらかじめ作った画像は使っていません。

| 切り替え | 何が起きるか |
|---|---|
| **Claw Wipe（クローワイプ）** | 6本の曲がった爪痕が、中心から映像を引き裂きます |
| **Furry Blur（ふわふわブラー）** | 毛並みのようににじんだ毛の霧。毛の流れに沿って映像が切り替わります |
| **Paw Spin（ポースピン）** | 巨大な肉球が中心から渦を巻いて現れ、その中に新しい映像があります |
| **Gentle Paw Fade（やさしい肉球フェード）** | 肉球の足跡が斜めにぽてぽてと進み、次のクリップへの窓を開きます |
| **Kitty Dash（キティダッシュ）** | 走る子猫がスピード線と肉球の跡を残して画面を駆け抜けます |
| **Meow Glitch（ニャーグリッチ）** | 裂けた走査線、RGBのずれ、ブロックの入れ替わり、ネオンの猫の顔 |

さらに**13種類のクラシックな切り替え**: クロスフェード、ブラックフェード、ホワイトフェード、ワイプ →、ワイプ ↓、プッシュ、ズーム、円形に開く、時計ワイプ、観音開き、モザイク、渦巻き、ぼかし。

### さらに25種類の切り替え（1.2）

これもすべてシェーダーで計算されます。切り替えタブに5つのグループがあります。

| グループ | 切り替え |
|---|---|
| **ノイズとセル** | *紙が燃える*（フラクタルノイズのしきい値と光る縁）、*粉々*（ボロノイのセルが順に倒れ、セルの境目は線として残る）、*水の中のインク*（煙のようなドメインワーピング） |
| **波と光学** | *水滴*（一点から広がる波紋）、*魚眼*（レンズのズーム）、*ズームブラー*、*スピンブラー*、*色収差*、*ライトリーク*（ガウス状の光の筋がカットを飛ばす） |
| **曲線と形** | *さくら*（5枚の花びらのバラ曲線）、*ハート開き*（陰関数のハート曲線）、*スパイラル*（アルキメデスの渦巻きで消す）、*肉球の花*（黄金角に並ぶ肉球＝フィロタキシス）、*ハニカム*（六角形が中心から順にめくれる）、*万華鏡*（角度を1〜8の鏡面に折りたたむ） |
| **マンガ風** | *ハーフトーン*（45°傾けたスクリーントーン）、*レトロディザ*（8×8のベイヤー行列）、*トラ柄*（ノイズで歪めた縞）、*三毛猫*（ボロノイの模様） |
| **3Dと物理** | *ページめくり*（円筒）、*キューブ*、*フリップ*（回転行列による透視投影）、*とろける*（列が y = ½gt² で落ちる）、*ドロステズーム*（対数極座標）、*フラクタル*（ジュリア集合の発散時間をマスクに使う） |

`cargo run -p hk-gpu --example contact_sheet -- transitions.png` は、すべての切り替えを5段階で1枚の画像に描き出します（`… transitions.png 19 6` なら20番目から6つだけ）。`--example single` は好きなサイズで1コマだけ描きます。

## 構成

```
crates/
  hk-core    時間（正確なティック）、プロジェクトモデル、編集操作、元に戻す／やり直す、保存。GPUもUIも使いません。
  hk-gpu     wgpu コンポジターと切り替えシェーダー。Rgba8 テクスチャに描画します（プレビュー、書き出し、テスト）。
  hk-media   画像（透明グラフィックを含む）、デモシーン、AVFoundation による動画（連続ハードウェアデコード、AVAssetWriter による MP4 書き出し）。
  hk-text    テキストのラスタライザー: フォント、折り返し、縁取り、影、背景ボックス。
  hk-audio   音声のデコード（symphonia）、波形、ミキサー、再生（cpal）。映像はオーディオクロックに合わせます。
apps/
  happy-kitten  egui の画面（オリジナルのパステルテーマ、手描きアイコン）、プレビューエンジン、書き出し。
```

設計ルール:

- **正確な時間。** すべて整数のティック（1秒あたり705,600,000。よく使うフレームレートとサンプルレートで割り切れます）で計算し、`f64` の秒は使いません。
- **プレビューと書き出しは同じパイプライン。** 同じコンポジターを使うので、見たままが書き出されます。
- **コアはウィンドウなしでテストできます。** `cargo test --workspace`。
- **`unsafe` は1か所だけ:** `hk-media` の Apple フレームワーク連携（動画の読み書き）です。

## 開発者向けヘルパー

マウス操作なしで自動チェックするための環境変数:

```bash
HK_LANG=ja                   # 言語を固定 (de, en, ja, ko, es)
HK_DEMO=1                    # 空のプロジェクトではなく、3つのサンプルシーンが入った状態で起動
HK_SCREENSHOT=out.png        # 少し待ってからウィンドウを保存して終了
HK_PLAYHEAD=5.0 HK_TAB=effects HK_IMPORT=clip.mp4:song.wav  # 再生ヘッド、タブ、インポートを事前設定
HK_PLAY=1                    # 再生を開始してオーディオクロックを出力
HK_EXPORT=film.mp4 HK_HEVC=1 # ダイアログなしで720pに書き出して終了
HK_GLOBAL=1 HK_IMPORT=folder # グローバルライブラリにインポート（開発実行では何も保存されません）
HK_TAB=color HK_SELECT_PICTURE=1   # 最初の画像クリップを選んで色タブを開く
HK_FX=echo HK_VOLUME=0.5 HK_FADE=1 HK_TEMP=0.6 HK_TINT=-0.3  # すべてのクリップに音と色の設定を適用
HK_BANNER=1                  # 緑色の「保存しました」通知を表示
HK_SCRIPT=build|text         # マウス操作を再生（ドラッグ、トリム、切り替え、テキスト、ライブラリ）。HK_DUMP=1 でタイムラインを出力
```

## filmcraft との関係

Happy-Kitten は [storytold/filmcraft](https://github.com/storytold/filmcraft)（MIT OR Apache-2.0）を参考にして作られました。線形パイプラインの wgpu コンポジター、正確な整数時間、特例ではなくコマンドで表す編集、UI に egui という考え方です。ただし**独自の軽量なコア**で、コードは一切引き継いでいません。filmcraft を依存ライブラリにしなかった理由は、filmcraft が Premiere 並みの機能（50以上のクレート、独自コーデック）を目指しているのに対し、Happy-Kitten は意図的に余計なものを持たないからです。filmcraft の純Rustコーデック（`h264`、`hevc`、`aac`、`isobmff` …）は、将来 Windows/Linux に移植するときの有力な選択肢です。
